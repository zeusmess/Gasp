# عاداتي الزجاجية — Daily Habits Glass 🪟💧

تطبيق أندرويد (APK) مساعد يومي للعادات الصحية، بتصميم زجاجي (Glassmorphism) وويدجت زجاجية للشاشة الرئيسية.

## المميزات
- **٨ عادات صحية جاهزة**: شرب الماء، التمدد، راحة العين ٢٠-٢٠-٢٠، المشي، التنفس العميق، الجلسة الصحيحة، الفاكهة والخضار، استراحة من الشاشة.
- **تذكير كل ساعة** على رأس الساعة، يختار العادة الأقل إنجازاً مع نصيحة صحية، وفيه زر **«✓ تم»** يسجّل العادة من الإشعار مباشرة.
- **ساعات التذكير** قابلة للتعديل (افتراضياً من ٨ ص إلى ١١ م) حتى لا يزعجك ليلاً، ويمكن إيقاف التذكير.
- **حلقة تقدم** متوهجة لنسبة إنجاز اليوم + عدّاد **أيام متتالية 🔥** (يوم ناجح = ٧٠٪ فأكثر).
- **إضافة عادات خاصة** بك (رمز، اسم، عدد مرات يومياً)، والضغط المطوّل للإنقاص/التصفير/الحذف.
- **تصفير تلقائي** للعدادات كل يوم جديد.
- **ويدجت زجاجية** شفافة تُظهر التاريخ ونسبة الإنجاز والعادة التالية مع زر **＋**، وزر سريع **💧** لكوب الماء، وموعد التذكير القادم.
- يعمل بعد إعادة تشغيل الهاتف، بدون إنترنت، وبدون أي مكتبات خارجية.

## التحميل والتثبيت
1. ادخل على صفحة **Releases** في المستودع وحمّل `DailyHabitsGlass.apk` (أو من تبويب **Actions** ← آخر تشغيل ← Artifacts).
2. افتح الملف على الهاتف واسمح بـ«التثبيت من مصادر غير معروفة».
3. عند أول فتح اسمح بالإشعارات. ولو ظهر تنبيه «المنبهات الدقيقة» اضغط عليه ليصل التذكير على رأس الساعة بالضبط.
4. لإضافة الويدجت: زر **«🪟 أضف الويدجت»** داخل التطبيق، أو اضغط مطولاً على الشاشة الرئيسية ← Widgets ← «عاداتي اليوم».

> نصيحة: على بعض الهواتف (شاومي، أوبو، هواوي…) فعّل «التشغيل التلقائي» واستثنِ التطبيق من توفير البطارية حتى لا تتوقف التذكيرات.

## البناء من المصدر
المتطلبات: JDK 17 و Android SDK (API 34) و Gradle 8.9.
```bash
cd daily-habits-app
gradle assembleRelease
# الناتج: app/build/outputs/apk/release/app-release.apk
```
يُبنى الـAPK تلقائياً عبر GitHub Actions (`.github/workflows/build-daily-habits-apk.yml`) عند أي تعديل داخل `daily-habits-app/`.

## البنية
| الملف | الوظيفة |
|---|---|
| `MainActivity.java` | الشاشة الرئيسية الزجاجية والإعدادات |
| `HabitStore.java` | تخزين العادات، التصفير اليومي، الأيام المتتالية |
| `ReminderScheduler.java` | جدولة منبه على رأس كل ساعة ضمن ساعات النشاط |
| `ReminderReceiver.java` | إظهار إشعار التذكير بأزرار «تم / لاحقاً» |
| `ActionReceiver.java` | تسجيل العادة من الإشعار أو الويدجت |
| `GlassWidgetProvider.java` | الويدجت الزجاجية |
| `ProgressRingView.java` | حلقة التقدم المتوهجة |
