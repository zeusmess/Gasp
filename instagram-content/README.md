# محتوى إنستجرام ديني: 5 بوستات يومياً بعد كل صلاة

## الملفات الجاهزة للنشر

كل يوم له فولدر في `out/<التاريخ>/`. اسم كل ملف بيبدأ بمعاد النشر (بتوقيت القاهرة):

| الملف | النوع | المحتوى |
|---|---|---|
| `0510-fajr.mp4` | فيديو متحرك (Reel) | أذكار الصباح، بعد الفجر |
| `1215-dhuhr.png` | صورة | بعد الظهر |
| `1510-asr.png` | صورة | بعد العصر |
| `1730-maghrib.mp4` | فيديو متحرك (Reel) | أذكار المساء، بعد المغرب |
| `1850-isha.png` | صورة | بعد العشاء |

- ملف `.txt` اللي بنفس الاسم فيه **الكابشن والهاشتاجات** جاهزين للنسخ.
- ملف `-cover.png` هو غلاف الفيديو (Cover) لو حبيت تختاره بنفسك.

## الجدولة على إنستجرام

1. افتح إنستجرام واعمل بوست جديد (أو Reel للفيديو)، واختار الملف.
2. انسخ الكابشن من ملف `.txt`.
3. ادخل على **Advanced settings**، فعّل **Schedule this post**، واختار المعاد اللي في اسم الملف.
4. دوس **Schedule**.

## للمطوّر: إعادة توليد التصاميم

```bash
node render.js content/2026-11-06.json          # يوم كامل
node render.js content/2026-11-06.json asr      # بوست واحد
```

- `content/*.json`: النصوص والمواعيد والكابشن لكل يوم.
- `template.html`: التصميم (الألوان لكل صلاة، الإطار، الزخارف، الحركة).
- الخطوط في `fonts/`: Amiri وAmiri Quran وAref Ruqaa وReem Kufi وNoto Naskh Arabic (كلها برخصة SIL Open Font License).
- محتاج: Node.js وPlaywright وffmpeg.
