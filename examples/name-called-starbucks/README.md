# الاسم اللي بيتنادى — The Name That Gets Called
موشن جرافيك ستوري 9:16 (1080×1920، 45 ثانية، 30fps) لستاربكس × أكتوبر الوردي.
GSAP + DrawSVG من مجلد `dist/` في الريبو، والخطوط محطوطة جوه المشروع (`fonts/`) عشان الفيديو يطلع نفس الشكل على أي جهاز.

## الفكرة
الباريستا بيكتب اسمك على الكوباية وبيناديه — أشهر طقس في ستاربكس.
**إيه اللي بيحصل لما اسم يتنادى… ومحدش يرد؟**

| # | الوقت | المشهد |
|---|---|---|
| ١ | 0–9s | **الروتين:** الماركر بيكتب «نادية» بخط رقعة، «نادية!»، الكوباية بتتاخد. السبت، الحد، الاتنين، التلات… كل مرة أسرع. |
| ٢ | 9–17s | **الصمت:** الأربع. «نادية!»… «نادية؟». محدش بيرد. الألوان بتنسحب، دوشة الكافيه بتختفي، الساعة بتجري (٨:٣٠ → ١:٠٠ م)، ونبض قلب. |
| ٣ | 17–22.6s | **الرقم:** الكاميرا بتبعد — ١٦ كوباية عليها أسامي (ماما، تيتة، سلمى…). اتنين منهم بيبهتوا. «واحدة من كل ٨ ستات». |
| ٤ | 22.8–26.3s | **الريوايند:** VHS — ألوان متفصصة، صوت شريط بيرجع، الأيام بترجع لورا. |
| ٥ | 26.3–31.4s | **التذكير:** «قبلها بأسبوعين» — نوتيفيكشن «الفحص الذاتي الشهري»، وليستة: عملت الفحص ✓ لاحظت تغيير بسيط ✓ حجزت كشف على طول ✓ |
| ٦ | 31.7–38.8s | **الرجوع:** «بعد ٦ شهور» — «نادية» + شريطة وردي + «وحشتينا ♥». «نادية!»… والكوباية **اتاخدت**. الألوان بترجع أدفى. |
| ٧ | 38.9–45s | **الإند كارد:** لوجو ستاربكس · «خلّي اسمك يفضل يتنادى. افحصي بدري.» · #اسمك_يتنادى · BY YOUSSEF AYMAN |

## التشغيل
```bash
# من جذر الريبو
npx http-server . -p 8080
# افتح: http://localhost:8080/examples/name-called-starbucks/
```

## تصدير MP4
```bash
cd examples/name-called-starbucks
npm i playwright && npx playwright install chromium
node render.mjs name-called.mp4 30        # فريمات + صوت
node render.mjs --audio-only              # يعيد تركيب الصوت بس على فيديو جاهز
```

## الصوت
`python3 sfx.py` (numpy + scipy) بيولّد بالكود:
- `audio/sfx` — دوشة كافيه (همهمة ناس، فناجين، ستيم الإسبريسو)، صوت الماركر على الورق، جرس الكاونتر، زحلقة ورفع الكوباية، تكّة الساعة ونبض القلب في الصمت، Pops للكوبايات، صوت شريط كاسيت بيرجع، نوتيفيكشن، Riser وImpact على اللوجو.
- `audio/music` — بيانو هادي (70 BPM) **بيقطع فجأة** لحظة ما محدش بيرد، Drone غامق في مشهد الرقم، وبعدين البيانو بيرجع ويكبر لحد اللوجو.

### الفويس أوفر (اختياري)
حط الملفات في `audio/` وشغّل `node render.mjs --audio-only`:

| الملف | الجملة | عند |
|---|---|---|
| `call.mp3` | صوت باريستا بينادي «نادية!» (بيتحط أوتوماتيك على كل نداء) | 2.9s، 5.8s، … |
| `vo1.mp3` | كل يوم… نفس الاسم، نفس الكوباية، نفس الميعاد. | 1.4s |
| `vo2.mp3` | لحد ما في يوم… الاسم يتنادى، ومحدش يرد. | 14.2s |
| `vo3.mp3` | واحدة من كل تمانية. | 19.0s |
| `vo4.mp3` | بس لما بنكتشف بدري… | 27.3s |
| `vo5.mp3` | …الحكاية بتكمل. | 36.8s |
| `vo6.mp3` | خلّي اسمك يفضل يتنادى. | 40.6s |
