# حضن وردي — Siren Hug
موشن جرافيك 9:16 (1080×1920، 16 ثانية): الحورية بتطلع من لوجو ستاربكس على الكوباية… وتحضنها.

| الوقت | المشهد |
|---|---|
| 0–2.6s | الكوباية في الكافيه — اللوجو بينوّر وردي · «أحيانًا… كلنا محتاجين حضن.» |
| 2.6–4.0s | الحورية بتطلع من اللوجو (3D pop + ظل + شرار) وبتسيب دايرة خضرا فاضية |
| 4.0–6.6s | بتطير فوق الكوباية، وبتنزل **وراها** — لونها بيتحوّل للأخضر وبتفتح دراعاتها (الديلين) |
| 6.9–8.5s | **الحضن** — الديلين بيلفوا حوالين الكوباية، الكوباية بتتعصر، توهج وردي، شريطة + قلوب |
| 8.6–12s | «ستاربكس معاكِ… في كل كوباية حضن.» |
| 12–16s | «افحصي بدري.» · أكتوبر الوردي · BY YOUSSEF AYMAN |

## إزاي الحورية اتفصلت
`parts/` اتعملت من `starbucks-logo.png`: كل الأجزاء البيضا في اللوجو اتقسّمت (connected components) لـ
التاج، الوش، الشعر، الجسم، الديل الشمال، الديل اليمين — كل جزء PNG بنفس مقاس اللوجو عشان يركبوا على بعض بالظبط.
في الكود الأجزاء بتتلوّن بـ SVG filter (أبيض → أخضر، وتوهج وردي)، والديلين بيلفوا من عند الكتف.

## التشغيل والتصدير
```bash
npx http-server ../.. -p 8080      # افتح /examples/siren-hug/
python3 sfx.py                      # يولّد الصوت (numpy + scipy)
node render.mjs siren-hug.mp4 30    # فريمات + صوت (playwright + ffmpeg)
```
