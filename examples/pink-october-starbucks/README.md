# صبّة أمل — Pink October Motion Story (GSAP)

موشن جرافيك ستوري 9:16 (1080×1920، ‏33 ثانية) معمول بـ GSAP + DrawSVG + MorphSVG من مجلد `dist/` في الريبو ده.
الفكرة والسكريبت الكامل في [`STORY.md`](./STORY.md).

## التشغيل
```bash
# من جذر الريبو
npx http-server . -p 8080
# افتح: http://localhost:8080/examples/pink-october-starbucks/
```
- `Space` إيقاف/تشغيل — زرار **إعادة** يعيد من الأول.

## تصدير فيديو MP4
محتاج `ffmpeg` متسطب.
```bash
cd examples/pink-october-starbucks
npm i playwright && npx playwright install chromium
node render.mjs pink-october.mp4 30
```
السكربت بيقف على كل فريم (`tl.seek`) ويصوّره — يعني الفيديو بيطلع ناعم ومظبوط بغض النظر عن سرعة الجهاز.

## المؤثرات الصوتية والميوزك
`python3 sfx.py` (محتاج numpy وscipy) بيولّد بالكود `audio/sfx.wav` و`audio/music.wav`، وكل مؤثر متظبط على توقيت الأنيميشن:
تكّة النقطة وهي بتقع، Boom لما الكوباية تظهر، صوت صب اللبن، Whoosh ولمعة مع تحوّل القلب لشريطة، Pops للـ٨ كوبايات، نبضة قلب، تيك-تاك التايمر، Chimes للجرابات الوردي، وRiser ثم Impact على اللوجو.
الميوزك: Pad هادي وبيانو Lo-fi (‏80 BPM)، بيبدأ حزين (D minor) ويقفل متفائل (F major) مع ظهور اللوجو.

ركّب الصوت على فيديو متصدّر من غير ما تعيد الفريمات:
```bash
node render.mjs --audio-only
```

## الفويس أوفر والميوزك (بيتركّبوا أوتوماتيك)
حط الملفات دي في فولدر `audio/` وشغّل `render.mjs` تاني — كل جملة هتتحط في توقيت مشهدها لوحدها:

| الملف | الجملة | بتبدأ عند |
|---|---|---|
| `audio/vo1.mp3` | كل أكتوبر… فيه حكاية بتبدأ بنقطة. | 0.4s |
| `audio/vo2.mp3` | واللي بيبان بدري… بيتلحق بدري. | 5.0s |
| `audio/vo3.mp3` | واحدة من كل تمانية ستات… ممكن تكون أي حد بنحبه. | 11.2s |
| `audio/vo4.mp3` | خمس دقايق في الشهر، أقل من وقت قهوتك… افحصي نفسك. | 16.4s |
| `audio/vo5.mp3` | ومش لوحدك… إحنا معاكي، في كل كوباية. | 22.4s |
| `audio/vo6.mp3` | افحصي، شاركي، وادعمي. ستاربكس… معاكي في أكتوبر الوردي. | 29.0s |
| `audio/music.mp3` | ميوزك خلفية (صوتها بيتوطّى تحت الفويس) | 0s |

كل جملة لازم تخلص قبل المشهد اللي بعده (حوالي ٤–٥ ثواني). التوقيتات في `VO_STARTS` جوه `render.mjs` لو حبيت تغيّرها.

**عشان صوت مصري واقعي:** سجّلها بصوت حقيقي (أفضل حاجة)، أو استخدم ElevenLabs (موديل Multilingual v2 وصوت عربي مصري من الـ Voice Library) أو Higgsfield. نزّل كل جملة في ملف لوحدها بالأسماء اللي فوق.

## اللوجو
`starbucks-logo.png` بيظهر في الإند كارد (بادج دايري جواه لمعة وحواليه حلقة وردي ودبوس شريطة) وعلى الكوبايات في مشهد التضامن. اللوجو علامة تجارية مسجلة لستاربكس — الفيديو ده **Spec / Portfolio** ومش إعلان رسمي.

## التعديل
كل المشاهد في Timeline واحد في `index.html` (القسم `①` لحد `⑥`):
- الكلام: الـ `div.cap` في الـ HTML.
- الألوان: متغيرات `:root`.
- التوقيت: الرقم الأخير في كل `.to(..., 10.2)` هو ثانية البداية.
